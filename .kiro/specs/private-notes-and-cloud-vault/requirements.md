# 需求文档：隐私笔记 & 云端保险库

## 功能概述

在现有「默认笔记」和「短消息中心（Chat）」之外，新增两个隐私相关的笔记入口：

1. **隐私笔记（Private Notes）** — 本地隐藏文件夹存储，入口隐蔽，界面完全不显示标题，仅切换编辑区内容
2. **云端保险库（Cloud Vault）** — 纯文本内容存储在 S3，每次打开需输入密码，入口在短消息（Chat）界面内

---

## 需求一：隐私笔记（Private Notes）

### REQ-P1：隐藏文件夹

- 隐私笔记存储在独立的 `private` zone，对应磁盘路径 `File/.private/`（以 `.` 开头，Windows 隐藏文件夹）
- 应用启动时自动创建该目录，并通过 Windows API 设置 `FILE_ATTRIBUTE_HIDDEN` 属性
- 新建的隐私笔记文件本身**不需要**设置隐藏属性，仅文件夹需要
- `private` zone **不出现**在资料库（LibraryPanel）、回收站、归档等任何普通笔记列表中
- `private` zone 的笔记**不参与** `llms.txt` / `mknote-manifest.json` 的 Agent 索引

### REQ-P2：隐藏入口

- 触发方式：`Ctrl + 鼠标左键` 点击左上角 Logo
- 进入隐私模式后，**仅替换编辑区内容**为最近一次打开的隐私笔记（或自动创建第一条）
- 以下 UI 元素**保持不变**（视觉上完全看不出切换）：
  - 顶部 Tab 栏：仍显示原来的普通笔记 Tab，不添加/切换任何 Tab
  - 顶部标题栏：仍显示原普通笔记标题
  - 底部状态栏：仍显示原普通笔记状态
  - 工具栏：保持不变
- 退出方式：点击 Tab 栏中的任意 Tab（触发正常的 `onSelectTab`）

### REQ-P3：隐私模式下的编辑行为

- 编辑区内容对应 `private` zone 的实际笔记文件，正常保存（防抖 600ms）
- 切换隐私笔记时（在私密空间内新建或切换），**不更新** Tab 栏和标题栏
- 支持在隐私模式下新建笔记（通过工具栏的「新建」按钮），新笔记创建在 `private` zone
- 退出隐私模式（点击任意 Tab）时，先保存当前隐私笔记内容，再切换回对应的普通笔记

### REQ-P4：隐私模式下不可见项

- 左下角状态栏的「资料库」按钮点击时**不打开**资料库（隐私模式下禁用，或直接退出隐私模式）
- 「回收站」「归档」「上传思源」等操作在隐私模式下**正常显示但操作对象是当前隐私笔记**（隐私笔记可以被归档/删除）

## 需求二：云端保险库（Cloud Vault）

### REQ-V1：入口位置

- 入口：短消息（Chat）界面内，发送框上方新增一个锁形图标按钮（复用现有 `lock_closed` icon）
- 布局位置：发送框（`message-hub-compose`）左上角，与 textarea 同一行顶部

### REQ-V2：密码机制

- **首次使用**：弹出「设置密码」对话框（两次输入确认），哈希后存入 S3 的独立配置文件（`MDnote/vault-config.json`）
- **后续使用**：弹出「输入密码」对话框，SHA-256 哈希后与 S3 存储的哈希比对
- 密码哈希算法：SHA-256，无 salt（简单防旁观者场景，不需要高强度加密）
- **锁定时机**：关闭 Chat 面板时，清空内存中的解锁状态；下次打开 Chat 面板后需重新输密码才能打开 Vault
- 密码验证在 Rust 后端完成（前端只传原始密码字符串，Rust 侧做哈希和比对）

### REQ-V3：内容存储

- 内容存储在 S3，object key：`MDnote/vault-notes.json`（独立于 `messages.json`）
- 复用现有 S3 配置（endpoint / bucket / access_key / secret_key）
- 数据结构与 `MessageHubStore` 相同（`{ version, entries: VaultEntry[] }`）
- `VaultEntry`：`{ id, text, created_at_ms }`
- 内容**明文**存储在 S3（安全模型：依赖密码门槛防旁观者，不做端对端加密）

### REQ-V4：界面

- 通过密码验证后，Chat 界面**在消息列表区域上方**叠加显示 Cloud Vault 面板（或替换列表区域）
- Vault 面板顶部：标题「云端私密」+ 右侧「锁定」按钮（点击立即清空内存状态并收起面板）
- 内容：纯文本列表，与短消息相同的列表风格（支持双击编辑、删除、复制）
- 输入：面板内有独立的文本输入框和「添加」按钮（不复用短消息的发送框）
- Vault 面板关闭方式：点击「锁定」按钮，或关闭 Chat 面板

### REQ-V5：无 S3 配置时的降级

- 若 S3 未配置，点击锁形按钮时显示提示：「请先在设置中配置短消息 S3 才能使用云端保险库」
- 不弹出密码框

---

## 不在范围内

- 隐私笔记**不需要**密码保护
- 隐私笔记**不需要**出现在任何列表、Tab、标题栏、状态栏
- Cloud Vault 内容**不需要**加密存储（明文 S3）
- Cloud Vault **不需要**支持 Markdown，纯文本即可
- Cloud Vault **不需要**离线缓存（每次打开都从 S3 拉取）
