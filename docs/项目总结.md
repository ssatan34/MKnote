## 一、这是什么项目

MKnote 是一款面向 **Windows** 的桌面 **Markdown 便签** 应用。每条便签对应本地一个 `.md` 文件，数据完全落在用户磁盘，不依赖云端账号。

项目用 **Tauri 2 + React 19 + Rust** 实现：前端负责编辑与界面，Rust 负责文件读写、系统集成与外部 API 调用。支持开发模式运行，也提供 **绿色便携版**（exe 与 `config.json`、便签目录同文件夹，拷走即用）。

**定位**：轻量、随手记、本地优先的便签本。  
**不是**：Obsidian 替代品、知识库系统、全功能云同步中心。

更完整的功能列表见 [功能概要.md](功能概要.md)；面向开发的实施路径见 [PROJECT-SUMMARY.md](PROJECT-SUMMARY.md)。

## 二、项目目的

1. **随手记**：全局热键唤起，无边框小窗，写完即存，关闭隐藏到托盘而不退出。
2. **文件即数据**：便签就是普通 Markdown，可用任意编辑器打开，便于备份与迁移。
3. **轻度组织**：内嵌资料库（文件夹 + 颜色标签 + 多标签页 + 回收站 + 归档），满足日常分类，不做复杂图谱。
4. **场景扩展**：胶囊 / Popout、S3 多设备同步、思源笔记单向上传或 Obsidian 文件复制、AI 划词助手、浏览器剪藏、Agent 索引等，在保持轻量的前提下覆盖常见工作流。
5. **可交付**：除源码开发外，提供绿色 zip 与 NSIS/MSI 安装包，方便非开发者使用。

## 三、技术栈

| 层级 | 技术 |
|------|------|
| 桌面壳 | Tauri 2 |
| 前端 | React 19、TypeScript、Vite 5 |
| 样式 | `tokens.css` 主题令牌 + `App.css` + Tailwind/shadcn 基础 |
| 后端 | Rust（`src-tauri/src/`） |

| 系统集成 | 托盘、全局热键、自启、单实例 |
| 打包 | `npm run build:green`（便携）、`npm run tauri build`（安装包） |

## 四、数据与目录

绿色版下，`{base}` 一般为 exe 所在目录：

```
{base}/
├── config.json              # 应用配置（含 S3、思源、AI、热键等）
├── inbox/                   # 收件箱便签
├── File/
│   ├── default/             # 默认区
│   ├── archive/             # 归档区
│   ├── <文件夹名>/          # 用户自建文件夹
│   ├── .mknote-note-colors.json
│   ├── .mknote-siyuan-map.json
│   └── assets/              # 图片资源
├── messages.json            # 短消息本地缓存（可选 S3 同步）
├── llms.txt                 # Agent 索引（自动生成）
└── mknote-manifest.json     # 便签清单（自动生成）
```

- 新建便签文件名：`YYYYMMDDHHmmssSSS.md`
- 列表标题 = 文件名去掉 `.md`
- 保存：输入防抖约 600ms；切换便签、隐藏窗口前会先 flush

### 全局热键（可配置）

### S3 同步配置（默认示例）

| 项 | 说明 |
|----|------|
| Endpoint | 如 `http://127.0.0.1:9000`（MinIO API 端口） |
| Bucket | 如 `mdnote` |
| Object Key | 如 `MDnote/messages.json` |
| 后端实现 | Rust `s3_store.rs`，reqwest + 手动 SigV4，`force_path_style` |

自动同步对象包括默认笔记、全部已注册 Quick Todo 和 Quick Pocket。4.2.2 移除了短消息聊天入口，仅保留 S3 同步设置。同步采用云端唯一权威模式：初始化从云端下载，本地不上传覆盖云端；非默认 Todo 内容使用 `MDnote/sync/quick-todo-{todo_id}.md`，注册表使用 `MDnote/sync/quick-todo-registry.json`；Pocket 对应使用 `MDnote/sync/quick-pocket-{pocket_id}.md` 和 `MDnote/sync/quick-pocket-registry.json`。

## 六、近期 UI / 交互更新（截至 2026-07-20）

0. **统一笔记窗口模式验收**：Popout 便签与胶囊默认走同一原生窗口 profile 切换；修复透明圆头、首次切换位移、切换裸重绘帧、左吸附镜像，并让胶囊默认置顶。
1. **胶囊模式验收**：主窗口与 Popout 均可进入胶囊；胶囊可拖拽、置顶、关闭、还原 Popout，并保持主窗口 Tab 状态一致。
2. **窗口形态转换**：Popout / Capsule 互转使用显式 Rust command，避免源窗口销毁时误触发 Tab 归还。
3. **主题同步**：主窗口主题切换会广播到 Popout / Capsule，分离窗口不再停留在旧主题。
4. **Tab 四向拖出**：主窗口 Tab 从上、下、左、右拖出窗口边界均可生成 Popout。
5. **截图后偶发置前修复**：收窄主窗口焦点事件处理，避免截图工具结束后应用被重复拉到前台。
6. **透明胶囊外观**：修复透明窗口四角黑底问题，置顶按钮保持可见。
7. **Quick Todo Stage C 验收与收口**：独立窗口复用同一 Panel/controller/Markdown 真相源，支持窗口几何、置顶和锁定持久化；默认未完成视图与已完成清理视图已经验收。YASB 的 `--toggle-quick-todo` 入口已满足设计初衷，不进入 Stage D 桌面停靠方案。
8. **Quick Pocket 与 Quick Todo 细节收口**：Quick Pocket 已具备独立窗口、主窗口入口、YASB `--toggle-quick-pocket` 入口、双击编辑、失焦保存、隐私打码、内文复制和稳定拖拽排序；空标题且空内文的 Pocket 不保存。两个窗口标题图标使用主题高亮色。Todo 使用独立 `check2.svg` / `done3.svg` 状态图标且不叠加 CSS 外圈，六类 Todo 标签按红/黄/蓝/紫/绿/橙显示，Pocket 内文摘要按条目标签着色。最新 release exe：`src-tauri/target/release/md-sticky-note.exe`。
9. **Quick 窗口生命周期收口**：Todo/Pocket 在稳定失焦后由 Rust 原生前台监控直接保存并隐藏；调整尺寸时保持可见。Todo 每次重新获得焦点重置到待办页。Quick 窗口已被授予 `allow-start-dragging` capability，顶部拖动恢复可用。根因与修复过程见 [2026-07-12-Quick窗口生命周期问题复盘.md](2026-07-12-Quick窗口生命周期问题复盘.md)。
10. **Quick Todo 父子项目验收**：Todo 支持两层父子结构，父项条目内可创建子项；子项用缩进、灰色文字和更紧凑行高区分父项。子项输入框空内容失焦即取消，Enter 保存，并可设置标签。子项拖拽只在同父级子项内生效；拖出当前组松手会恢复全量列表，不会隐藏父 Todo。右上角关闭按钮退出原生拖动区域，可直接关闭 Quick Todo 窗口。
11. **Quick Todo v4.1.1 定时提醒与笔记链接**：Todo 支持一次性 Windows Toast 定时提醒、按天/月/年规则显示倒计时、提醒到期自动清除；工具栏新增并固定链接操作顺序。链接按笔记标题搜索并保存 `zone + name`，覆盖默认、收件箱、私密、存档和资料库文件夹。点击已保存链接调用 `open_note_popout` 打开真正的便签窗口，不进入胶囊模式。
12. **2026-07-16 Quick 窗口 UI 收口**：提醒设置切为独立原生窗口，优先显示在 Quick Todo 左侧；保存按钮直接共用主窗口 `mk-save-button`。Todo 的闹钟、添加子项目和关联便签操作默认隐藏，行悬浮、键盘焦点进入或关联菜单打开时才显示，且固定操作区宽度避免布局跳动。详见 [HANDOVER-2026-07-16-ui-and-quick-windows收口.md](HANDOVER-2026-07-16-ui-and-quick-windows收口.md)。
13. **2026-07-16 / 2026-08-21 Quick 标签筛选**：Quick Pocket 底部支持文本、命令、路径、隐私四类筛选；Quick Todo 右下角支持重要、等待、下一步、想法、紧急、重要紧急六类筛选，其中紧急使用绿色闪电图标、重要紧急使用橙色辐射圆图标。再次点击当前标签恢复默认列表；Quick Todo 筛选状态下禁用拖拽手柄，避免破坏现有父子排序契约。
14. **2026-07-20 Quick Pocket 单层分组**：两个未分组条目拖拽到中间区域可创建命名分组；支持组名双击重命名、组内新增、解散、条目跨组移动与整组排序。分组与普通条目统一混排，少于两个成员时自动解散，不支持空分组、单条目分组或嵌套。标签筛选时忽略分组结构并禁用跨分组拖拽；分组折叠状态在前端持久化。完整交互见 [MKnote-UI-v2.md](MKnote-UI-v2.md)。
15. **2026-07-21 多 Quick Pocket v4.1.3 分支实现**：保留现有 `inbox/Quick Pocket.md` 作为默认 Pocket，不迁移、不改名；项目设置新增 Pocket 管理板块，可创建、命名和删除 Pocket，名称最多 6 个字符，默认 Pocket 不可命名或删除。左下角 Quick Pocket 按钮仅打开 Pocket 选择器，选择器只负责打开已有 Pocket，宽度调整为 130px，并支持失焦自动关闭。设置中的新 Pocket 输入区同时支持 Enter 和 Save 按钮创建，重命名 Save 复用统一保存按钮样式；非默认 Pocket 的删除按钮左侧增加复制 ID 按钮，复用 Quick Pocket 的复制反馈图标；Pocket 管理条目保持原有整行悬浮背景高亮，复制按钮悬浮时仅高亮复制图标线条。独立 Pocket 窗口左上角标题显示对应 Pocket 名称。新 Pocket 使用稳定 ID 创建全新的 Markdown 文件，UI、标签、分组、保存和窗口逻辑复用默认 Pocket；Pocket 之间数据隔离，支持通过 `--quick-pocket=<pocket_id>` 或 `--toggle-quick-pocket=<pocket_id>` 由 YASB 直达指定 Pocket。详细规格见 [MKnote-UI-v2.md](MKnote-UI-v2.md)。
16. **2026-07-28 Quick Todo / Quick Pocket 一致性修复**：Todo 写操作按触发顺序串行落盘并拒绝旧请求覆盖新列表；Pocket 切换和管理操作增加请求序号保护；非默认 Pocket 删除使用文件暂存与配置回滚；同步不再用旧远端基线立即覆盖 Quick Todo/Pocket 的本地 CRUD。绿色版流程整理为 `.agents/skills/mknote-green-package` Skill。
17. **2026-08-06 多 Quick Todo**：保留 `inbox/Quick Todo.md` 作为默认 Todo，不迁移、不改名；设置新增 Todo 管理，状态栏 Todo 按钮改为选择器。每个 Todo 使用稳定 ID、独立 Markdown、独立窗口/提醒/置顶/锁定状态，并支持按 ID 的 CLI 与 S3 同步。
