## 一、本轮调整内容

### 1. 状态栏按钮顺序修正（按截图对齐）

最终顺序：

```
[资料库] [最近] [回收站] [自启] [上传思源] [归档] [删除] · 本地·已保存 · [spacer] · [字数] | [行数]
```

变更：将「本地·已保存」状态文字从`上传/归档/删除`左边移到右边，操作按钮组直接跟在自启之后。

---

### 2. 模板弹窗文字显示修复

问题根源：弹窗 `min-width` 不足，grid 列宽被压缩导致文字省略。

修复：
- 弹窗改为 `width: max-content`，由内容撑开，上限 `max-width: min(480px, calc(100vw - 80px))`
- 按钮和标签均设 `white-space: nowrap`，完整显示「会议记录」「旅行准备」等4字标签

---

### 3. Tab 置顶区域重构（Grid 布局）

| 项目 | 变更前 | 变更后 |
|------|--------|--------|
| 布局方式 | flex wrap，tab 固定 80px | CSS Grid 两列，tab 撑满列宽 |
| 置顶区总宽 | max-width: 220px | 固定 180px |
| 1个tab时 | 占一列，右侧空白 | `:has(:only-child)` 横跨两列 |
| 选中宽度 | active 撑到 96px | 与普通态同宽，不撑大 |
| pin icon | 常亮主题色 | 常态灰色，hover/active 变主题色 |
| overflow-wrap 空位 | `regularTabs.length > 0` 时占 56px | 改为 `overflowRegularTabs.length > 0`，无溢出时宽度归零 |

---

### 4. 置顶标签数量可配置

新增功能，在设置面板「系统」组 → 快捷键下方新增「**标签页设置**」路由。

**实现链路：**

- `AppConfig`（Rust + TS）新增 `pinned_tab_limit: u8`，默认 2，范围 1–10
- 新增 Tauri 命令 `set_pinned_tab_limit`，保存时自动截断超出的置顶标签
- 前端 `tabPin.ts` 的 `MAX_PINNED_TABS` 常量保留作 fallback，运行时读 `pinnedTabLimitRef.current`
- `TabLimitPanel` 组件：使用 1–10 的数字输入，失焦或回车后保存
- `UnifiedSettingsPanel` 新增 `tabLimit` 路由，加入左侧导航（icon: `lock_closed2`）

**CSS：**`.tab-limit-input-row` / `.tab-limit-input` / `.tab-limit-desc`

---

### 5. 统一滚动条设计（Figma 规格落地）

设计规格（来源：Figma 设计稿 `38lcvAd0l26nBkPJXYiTKp`）：
- 宽度 **5px**，纤细浮动，不占内容空间
- 轨道**透明**，只保留 thumb
- 圆角 **99px**，完整胶囊形态
- 过渡 **150ms ease-out**，hover 时 thumb 加深

**Token 化（`tokens.css`）：**

每个主题块新增 `--mk-scrollbar` / `--mk-scrollbar-hover`，由 `--mk-primary` 派生：

| 主题 | thumb 透明度 | hover 透明度 |
|------|-------------|-------------|
| MKnote / Catppuccin / Poseidon / Ares | 22% | 50% |
| Hermes（金色，视觉需加深） | 25% | 54% |

覆盖范围：所有浅色主题块、所有深色主题块、`@media prefers-color-scheme: dark` 中的 system 变体。

**CSS（`App.css` 批量选择器）：**

统一覆盖以下区域（webkit + Firefox 双端）：
`.editor` / `.editable-preview` / `.markdown-preview` / `.library-panel-folders` / `.library-panel-notes` / `.library-folder-notes` / `.settings-panel-nav` / `.settings-panel-content` / `.trash-list` / `.note-tabs-overflow-menu` / `.ai-assist-result` / `.mk-floating-popover` / `.search-results` / `.todo-template-view`

`NoteTabsBar.css` 中的 tab 横向滚动条同步从旧 4px + `var(--mk-muted)` 换成 5px + `var(--mk-scrollbar)`。
