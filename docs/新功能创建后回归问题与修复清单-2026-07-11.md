## 关键设计决策

| 决策 | 原因 | 影响 |
|---|---|---|
| 配置只允许单写者并原子替换 | 多窗口并发写是 JSON 尾部损坏的根因 | 后续所有窗口共享同一安全保存路径 |
| 截图遮罩作为独立状态，不等同于“非全屏” | 直接返回 false 会在 `Fullscreen → CaptureOverlay` 时错误恢复主窗口 | 全屏避让状态在截图期间保持稳定 |
| Win32 原子设置窗口 bounds | 分开的 size/position 会产生可见中间帧，也可能被原生拖动事务覆盖 | Windows 恢复和首次收纳不再依赖两个异步原生操作 |
| Rust watcher 独占悬浮收纳控制 | 多个前后端控制器会互相覆盖位置 | React 只负责用户拖动和呈现状态 |
| 有限复查且成功即停 | 单次固定延迟可能早于 Windows 拖动结束；无限/多次无条件 settle 又会破坏 watcher | 最多三次读取最终位置，吸附成功后不再修改状态 |
