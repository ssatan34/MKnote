## 一、本轮调整内容

### 1. 新功能：默认便签

**需求**：顶部标题栏新增【默认便签】按钮，点击后切换到一个固定的便签，不进入标签栏，类似待办事项的独立激活态。

**实现细节**：

| 项 | 说明 |
|----|------|
| 文件路径 | 根目录 `default-note.md`，与 exe 同级 |
| 初始内容 | `默认便签` |
| 启动时行为 | `get_app_state` 调用 `ensure_default_note`，不存在则自动创建 |
| 按钮位置 | 标题栏 💬（短消息）左边，紧贴，间距参考搜索按钮组 |
| 图标 | `default-note.svg`（house 图形），已注册 manifest |
| 标题栏 | 显示固定文字"默认便签"，完全只读，不可重命名 |
| 标签栏 | 进入默认便签时隐藏标签栏，独立激活态 |
| 删除保护 | 删除按钮在默认便签激活时禁用（tooltip 提示"默认便签不可删除"） |
| 保存路径 | 专用 Rust command `write_default_note`，不走 zone 路径 |
| 退出方式 | 再次点击按钮返回上一个普通便签；点击任意标签也可返回 |
| 热键 | 不改变现有 `Ctrl+Shift+Alt+M` 行为 |

**涉及文件**：
- `src-tauri/src/notes.rs`：新增 `DEFAULT_NOTE_NAME` 常量、`ensure_default_note()`、`is_default_note()` 函数
- `src-tauri/src/lib.rs`：注册 `ensure_default_note`、`read_default_note`、`write_default_note` 三个 command；`get_app_state` 启动时调用 `ensure_default_note`
- `src/App.tsx`：新增 `DEFAULT_NOTE_NAME` 常量、`isDefaultNote()` 函数、`defaultNoteOpen` 状态、`handleOpenDefaultNote` handler；`writeNoteQueued` 对 `default-note.md` 走专用 command
- `src/components/CompactView.tsx`：顶栏加按钮、标题只读逻辑、删除按钮禁用、标签栏隐藏
- `src/assets/icons/default-note.svg`：新增图标
- `src/assets/icon-manifest.json`：注册 `default_note`

### 2. Bug 修复：标签栏从两行变一行时窗口反复抖动

**根因**：`setIsTwoRowLayout(false)` 触发 re-render → bar 高度缩小 → `ResizeObserver` 触发 → 重新测量 → 再次触发，形成死循环。

**修复方案**：从 true→false（收缩）时加 120ms 防抖，等高度稳定后再确认；从 false→true（扩展）时仍立即更新。

**涉及文件**：
- `src/components/NoteTabsBar.tsx`：新增 `twoRowCollapseTimerRef`，修改 `remeasureTabs` 中 `setIsTwoRowLayout` 的触发逻辑，组件卸载时清理定时器
