## A. 稳定性（Phase 0）

### A1 · 退出/隐藏前自动保存

- **怎么用**：点顶栏关闭、托盘「隐藏/退出」
- **说明**：会先 flush 当前标签 + 所有脏标签，再隐藏/退出
- **完成度**：完整（正常路径）；任务管理器强杀仍可能丢最后 ~600ms 内容

**意见：无意见**



### A2 · 文件名校验（前端）

- **怎么用**：重命名便签、改标题
- **说明**：实时过滤 `\ / : * ? " < > |`，非法字符无法提交
- **完成度**：完整

**意见：无意见**



### A3 · 思源路径防冲突

- **怎么用**：上传思源时自动
- **说明**：非 `default` zone 的便签上传到 `/MKnote/标题_(inbox)` 等；映射按 zone+文件名
- **完成度**：完整

**意见：无意见**



### A4 · 预览编辑 HTML 清洗

- **怎么用**：预览模式编辑后回写
- **说明**：去空标签、统一块结构，减少 Markdown 脏格式
- **完成度**：完整

**意见：无意见**

## B. 捕获与检索（Phase 1）

### B1 · Quick Capture 快速输入

- **怎么用**：全局 `Ctrl+Alt+N`
- **说明**：弹出居中输入框，Enter 保存到 Inbox，时间戳文件名
- **完成度**：完整

**意见：取消该功能，本身项目的出发点就是快速记录**



### B2 · 剪贴板一键收集

- **怎么用**：全局 `Alt+Shift+C`
- **说明**：静默读剪贴板文本 → Inbox 新便签 + 右下角 Toast
- **完成度**：完整

**意见：有重大bug，一次会生成大量笔记**



### B3 · 全文搜索 Omnibox

- **怎么用**：全局 `Ctrl+P`（窗口内也监听）
- **说明**：搜文件名 + 正文；回车打开便签
- **完成度**：完整

**意见：搜索栏中输入的文字颜色过浅，这里的ui设计需要与主题保持一致，全文搜索需要有个按钮，可以放在标题搜索按钮的左边**



### B4 · 高级搜索语法

- **怎么用**：在 Omnibox 输入
- **说明**：`folder:inbox` · `color:重要` · `modified:7d` · `todo:`
- **完成度**：完整

**意见：无意见**



### B5 · 最近访问

- **怎么用**：资料库顶部「最近」
- **说明**：最多 20 条，打开便签时记录；与多标签 `open_tabs` 分开
- **完成度**：完整

**意见：现在这个ui方式不行，会占据大量窗口资源，我建议在左下角“展开资源库”按钮的右边，“上传思源”按钮的左边，新增一个icon，点击可以展开一个独立的ui，看见10条最近访问过的笔记**



### B6 · 标题搜索（0.1 原有）

- **怎么用**：顶栏搜索按钮
- **说明**：仍保留，只搜当前资料库范围的标题（与 B3 是两套入口）
- **完成度**：0.1 原有，未替换

**意见：无意见**

## E. 进阶能力（Phase 4）

### E1 · 分离窗口 Detach

- **怎么用**：左侧工具栏「分离窗口」
- **说明**：单篇便签独立小窗（~240×280），可编辑、定时保存；未做：收边细条、颜色标签背景

- **怎么用**：选中文本 → 工具栏「AI」
- **说明**：润色 / 摘要 / 翻译 / 续写；需在 `config.json` 配置 `ai_config`，无设置 UI
- **完成度**：需配置

- **完成度**：需配置
