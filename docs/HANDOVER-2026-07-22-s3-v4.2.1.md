# MKnote v4.2.1 S3 多 Pocket 同步交接

## 已完成

- 自动同步默认笔记、Quick Todo、默认 Quick Pocket 和全部已注册 Quick Pocket。
- 同步触发：应用启动、定时轮询、窗口获得焦点、本地内容变更。
- 云端为唯一权威源，初始化只允许从云端下载；本地不会上传覆盖云端。
- 远端对象缺失时保持本地不动，不把缺失解释为删除，也不反向上传恢复。
- 本地与云端不一致时先写入 `.mknote-sync-conflicts/`，再采用云端版本；默认笔记正在编辑时暂缓覆盖。
- 使用 ETag 条件写入和 manifest 冲突重试，保留既有 S3 兼容实现。

## S3 对象

```text
MDnote/sync/default-note.md
MDnote/sync/quick-todo.md
MDnote/sync/quick-pocket-default.md
MDnote/sync/quick-pocket-{pocket_id}.md
MDnote/sync/quick-pocket-registry.json   # 可选，云端 Pocket ID/名称注册表
MDnote/sync/manifest.json
```

注册表存在时，设备会从云端恢复 Pocket ID 和名称；不存在时兼容本地已有注册表。由于当前策略禁止本地上传覆盖，新增 Pocket 的云端注册表需要先在云端建立正确版本。
