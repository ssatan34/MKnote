## 一、本轮调整内容

### 1. 状态栏布局重排

**变更前：**
```
[资料库] [最近] [回收站] [自启] · 本地·[状态] · [spacer] · [上传][归档][删除] · [spacer] · [字数] | [行数]
```

**变更后：**
```
[资料库] [最近] [回收站] [自启] · 本地·[状态] · [上传][归档][删除] · [spacer] · [字数] | [行数]
```

- 移除了 `上传/归档/删除` 左侧的 spacer，使这三个按钮紧随"本地·已保存"状态文字
- 移除了原来在 `上传/归档/删除` 右侧的 spacer，右侧仍保留一个 spacer 撑开字数统计
- 操作按钮组（`statusbar-note-actions`）不再独立居中，而是自然排列在状态文字之后

### 2. 模板选项加 Icon

- `TEMPLATE_COLUMNS` 从 `string[][]` 改为 `TemplateItem[][]`，每项含 `id`（模板名）和 `icon`（icon id）
- 模板弹出列表每个按钮改为 `icon + 文字` 布局（CSS flex，gap 6px）
- 新增 CSS 类 `.template-item-icon` 和 `.template-item-label`
- 新增 9 个 SVG 占位 icon 文件：

| 模板 | Icon ID | SVG 文件 |
|------|---------|----------|
| 会议记录 | `template_meeting` | `icons/template-meeting.svg` |
| 今日工作 | `template_today` | `icons/template-today.svg` |
| 沟通记录 | `template_comms` | `icons/template-comms.svg` |
| 购物清单 | `template_shopping` | `icons/template-shopping.svg` |
| 旅行准备 | `template_travel` | `icons/template-travel.svg` |
| 阅读摘录 | `template_reading` | `icons/template-reading.svg` |
| 资料暂存 | `template_stash` | `icons/template-stash.svg` |
| 概念卡片 | `template_concept` | `icons/template-concept.svg` |

所有 icon 均为 24×24 线条风 SVG 占位，样式与现有图标一致（stroke currentColor）。
**可直接替换对应文件**，不需要改代码。

### 3. 剪贴板粘贴图片

**前端（`CompactView.tsx`）：**
- 新增 `handlePaste` 回调（`useCallback`），监听 `document` 的 `paste` 事件
- 检测 `ClipboardData.items` 中的 `image/*` 类型文件
- 读取为 `ArrayBuffer` → `number[]`，通过新 Tauri 命令 `import_clipboard_image` 保存
- 保存成功后调用 `insertImageMarkdown` 插入 `![图片](...)` 语法并切换预览
- 非图片粘贴不受影响（文字粘贴走浏览器默认路径）

**Rust（`src-tauri/src/assets.rs`）：**
- 新增 `import_clipboard_image(app, ext, data: Vec<u8>)` 函数
- 对数据做 SHA-256 哈希去重，文件名格式 `{short_hash}.{ext}`，存入 `File/assets/`
- 支持扩展名：`png`、`jpg`、`gif`、`webp`、`bmp`（其他默认 `png`）
- 新增内部工具函数 `sanitize_ext`

**Rust（`src-tauri/src/lib.rs`）：**
- 注册新 Tauri 命令 `import_clipboard_image`，加入 `generate_handler!` 列表

## 五、Icon 替换指南

模板 icon 均为占位 SVG，可按需替换：

1. 找到对应文件（如 `src/assets/icons/template-meeting.svg`）
2. 替换为你的 SVG，保持 `width="24" height="24"`，stroke 用 `#333333`（会被自动替换为 currentColor）
3. 无需改代码，Vite 会自动 hot-reload
