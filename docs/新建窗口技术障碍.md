# 便签弹出窗口（Pop-out）技术障碍说明

> 生成时间：2026-07-06  
> 项目：MKnote（Tauri 2 + React + TypeScript + Vite）

---

## 目标功能

Tab 右键菜单 → "在新窗口中打开" → 创建一个独立的极简便签窗口（PopoutView），与主窗口并行存在。关闭时 Tab 归还主窗口。

---

## 当前状态

- Tab 右键菜单已实现（`NoteTabsBar.tsx`）
- 弹出窗口 UI 组件已实现（`PopoutView.tsx`）
- Rust 命令 `open_note_popout` / `close_note_popout` 已实现（`detach.rs`）
- 主窗口的 Tab 隐藏、Tab 归还、事件监听逻辑均已实现（`App.tsx`）
- **弹出窗口打开后始终白屏，React 完全未渲染**

---

## 核心障碍：动态窗口无法加载前端内容

### 障碍1：URL 参数丢失（已确认）

Tauri 2 dev 模式下，`WebviewWindowBuilder` 使用 `WebviewUrl::App` 创建动态窗口时：

- `WebviewUrl::App("index.html?detach=1&zone=xxx")` → 窗口实际加载 `http://localhost:1420/`，**query string 完全丢失**
- `WebviewUrl::App("/?detach=1&zone=xxx")` → 同上，query 丢失
- `WebviewUrl::App("/#detach=1&zone=xxx")` → hash 同样丢失
- Console 确认：`[main.tsx] href= http://localhost:1420/  isDetach= false`

**尝试过 `WebviewUrl::External("http://localhost:1420/?detach=1&...")`**，但 Tauri 2 的 build script 报错 `Permission core:webview:allow-navigate not found`（该 permission 不存在）。

### 障碍2：窗口 label 识别方案，当前实现版本（未验证能否成功）

鉴于 URL 传参全部失败，改为：
1. 弹出窗口 label 以 `popout-` 开头
2. `main.tsx` 通过 `getCurrentWindow().label` 判断，若以 `popout-` 开头则渲染 `PopoutView`
3. `PopoutView` 监听 `mknote:popout-init` Tauri 事件接收 zone/name/title
4. Rust 侧在窗口创建后起一个线程，轮询 emit `mknote:popout-init`（最多 3 秒）

**此方案尚未验证，弹出窗口依然白屏**，原因未知（可能是 `getCurrentWindow().label` 在弹出窗口的加载阶段不可用，或事件时序问题）。

## 完整文件现状

### `src/main.tsx`（当前版本）

```tsx
import ReactDOM from "react-dom/client";
import "./styles/tokens.css";
import "./styles/tailwind.css";
import App from "./App";
import { PopoutView } from "./components/PopoutView";
import { UiPlayground } from "./pages/UiPlayground";
import { getCurrentWindow } from "@tauri-apps/api/window";

const isUiPlayground = new URLSearchParams(window.location.search).get("ui-playground") === "1";

async function main() {
  if (isUiPlayground) {
    ReactDOM.createRoot(document.getElementById("root") as HTMLElement).render(<UiPlayground />);
    return;
  }

  // 通过窗口 label 判断是否为弹出窗口
  const label = getCurrentWindow().label;
  const isPopout = label.startsWith("popout-");

  if (isPopout) {
    ReactDOM.createRoot(document.getElementById("root") as HTMLElement).render(<PopoutView />);
  } else {
    ReactDOM.createRoot(document.getElementById("root") as HTMLElement).render(<App />);
  }
}

void main();
```

### `src-tauri/src/detach.rs`（当前版本）

```rust
use tauri::{Emitter, Manager, WebviewUrl, WebviewWindowBuilder};
use crate::system::WINDOW_LABEL;

fn popout_label(zone: &str, name: &str) -> String {
    format!(
        "popout-{}-{}",
        zone.replace(':', "_"),
        name.replace('.', "_").replace(' ', "_")
    )
}

#[tauri::command]
pub fn open_note_popout(
    app: tauri::AppHandle,
    zone: String, name: String, title: String,
    width: f64, height: f64,
) -> Result<(), String> {
    let label = popout_label(&zone, &name);

    if let Some(w) = app.get_webview_window(&label) {
        let _ = w.show();
        let _ = w.set_focus();
        return Err("already_open".into());
    }

    let w = width.max(400.0);
    let h = height.max(300.0);

    // URL 不带任何参数（dev 模式下参数会丢失）
    let url = WebviewUrl::App("/".into());
    let window = WebviewWindowBuilder::new(&app, &label, url)
        .title(&title)
        .inner_size(w, h)
        .min_inner_size(400.0, 300.0)
        .decorations(false)
        .always_on_top(false)
        .resizable(true)
        .build()
        .map_err(|e| e.to_string())?;

    // 轮询 emit 初始化参数（最多 3 秒）
    let app_for_init = app.clone();
    let label_for_init = label.clone();
    let zone_for_init = zone.clone();
    let name_for_init = name.clone();
    let title_for_init = title.clone();
    std::thread::spawn(move || {
        for _ in 0..30 {
            std::thread::sleep(std::time::Duration::from_millis(100));
            if let Some(w) = app_for_init.get_webview_window(&label_for_init) {
                let result = w.emit("mknote:popout-init", serde_json::json!({
                    "zone": zone_for_init,
                    "name": name_for_init,
                    "title": title_for_init
                }));
                if result.is_ok() { break; }
            }
        }
    });

    // 监听关闭事件
    let app_handle = app.clone();
    let zone_clone = zone.clone();
    let name_clone = name.clone();
    window.on_window_event(move |event| {
        if let tauri::WindowEvent::Destroyed = event {
            if let Some(main) = app_handle.get_webview_window(WINDOW_LABEL) {
                let _ = main.emit("mknote:popout-closed",
                    serde_json::json!({ "zone": zone_clone, "name": name_clone }));
            }
        }
    });

    Ok(())
}
```

## 已尝试过的方案（全部失败）

| 方案 | 结果 | 失败原因 |
|------|------|---------|
| `WebviewUrl::App("index.html?detach=1&zone=xxx")` | 白屏 | query string 被丢弃，加载 `http://localhost:1420/` |
| `WebviewUrl::App("/?detach=1&zone=xxx")` | 白屏 | 同上 |
| `WebviewUrl::App("/#detach=1&zone=xxx")` | 白屏 | hash 同样被丢弃 |
| `WebviewUrl::External("http://localhost:1420/#detach=1&...")` | 编译失败 | `core:webview:allow-navigate` permission 不存在 |
| 窗口 label 识别 + 事件推送 | 白屏 | 未能验证 label 方案的问题所在 |
