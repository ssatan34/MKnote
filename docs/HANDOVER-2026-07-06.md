## 本轮完成功能

### 功能一：脚本胶囊

笔记首行写 `!p` 或 `!power`，左侧竖向工具栏出现 ⚡ 按钮，点击后将笔记正文（去除首行标记）作为 PowerShell 脚本执行，结果以 toast 显示（成功绿色，失败红色，5 秒自动消失）。

**关键实现细节：**
- 执行使用 `spawn_blocking` + 30 秒超时轮询，不阻塞 Rust 命令线程
- 编辑模式和预览模式的工具栏均可见该按钮
- 图标占位文件：`src/assets/icons/run-script.svg`，可直接替换为正式图标

**涉及文件：**
- `src-tauri/src/scripts.rs`（新建）
- `src-tauri/src/lib.rs`：注册 `mod scripts` 和 `run_script` 命令
- `src/assets/icons/run-script.svg`（新建，占位）
- `src/assets/icon-manifest.json`：注册 `run_script` 图标
- `src/components/CompactView.tsx`：检测首行、按钮渲染、toast 显示

### 功能二：全屏避让

设置面板新增「基础设置」分组，内含「全屏时自动隐藏」开关（默认关闭）。开启后，检测到前台窗口占满显示器时自动隐藏 MKnote 到托盘；全屏结束后自动恢复窗口位置。

**关键实现细节：**
- 后台线程每 2 秒轮询一次前台窗口，CPU 开销可忽略
- 用 `AtomicBool` 区分「因全屏避让隐藏」和「用户主动隐藏」，避免误恢复
- 检测逻辑排除 MKnote 自身窗口
- 线程始终运行，通过读取配置决定是否执行避让（无需重启应用即可生效）
- 仅 Windows 平台启用，非 Windows 为空实现
- `Win32_Graphics_Gdi` feature 已补充到 `Cargo.toml`

**已知局限：**
- 使用 `GetForegroundWindow` + 矩形比对方案，对部分 DirectX 独占全屏游戏可能漏检，需实机验证
- 全屏结束后恢复调用 `show_main_window`，会恢复到上次保存的窗口几何位置

**涉及文件：**
- `src-tauri/src/fullscreen_watcher.rs`（新建）
- `src-tauri/src/lib.rs`：`AppConfig` 新增 `fullscreen_dodge` 字段 + `set_fullscreen_dodge` 命令
- `src-tauri/src/system.rs`：setup 中启动 watcher 线程
- `src-tauri/Cargo.toml`：补充 `Win32_Graphics_Gdi` feature
- `src/types.ts`：`AppConfig` 添加 `fullscreen_dodge` 字段
- `src/components/CompactView.tsx`：设置面板「基础设置」分组 + toggle 开关
- `src/App.tsx`：`handleFullscreenDodgeChange` 回调
- `src/App.css`：toggle 开关样式、settings-row 布局样式
