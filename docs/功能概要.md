## 项目目的

MKnote 要解决的是：**在 Windows 上快速记下 Markdown 便签，且数据完全留在本地。**

- 像便签一样轻：热键唤起、小窗编辑、关窗不退出、托盘常驻。
- 像文件一样可靠：一条便签一个 `.md`，备份、同步盘、版本管理都按文件处理。
- 像工具一样顺手：资料库分类、颜色标签、多标签页、胶囊 / Popout，覆盖日常记录与轻量提醒。

**不做**重型知识库、双向同步、在线协作。需要深度笔记或图谱时，应使用 Obsidian 等专用工具；MKnote 负责「快写、快找、快走」。

## 核心功能一览

### 编辑与显示

| 功能 | 说明 |
|------|------|
| Markdown 源码编辑 | 纯文本编辑，防抖自动保存 |
| 可视化预览编辑 | 预览模式下直接改内容，回写 Markdown |
| 可视化预览工具条 | 查找替换、表格行列编辑与左/中/右对齐以图标呈现；分割线和插入表格使用上方 Markdown 工具栏 |
| 格式工具栏 | 加粗、斜体、删除线、下划线、高亮、标题、列表、引用、代码、链接、图片、表格等 |
| 编辑 / 预览切换 | 顶栏一键切换 |
| 字号调节 | 12–24px，写入配置 |
| 多标签页 | 同时打开多条便签，重启恢复；常规与置顶 Tab 可右键复制笔记完整路径 |
| 撤销 / 重做 | 编辑历史 |
| 本地隐私笔记 | 状态栏字数 Ctrl+点击进入；保存至 `File/.private/`，不进入资料库、Agent 索引或笔记上传 |

### 便签与资料库

| 功能 | 说明 |
|------|------|
| 本地 `.md` 存储 | 每条便签独立文件，标题即文件名 |
| Inbox / Default / 自定义文件夹 | 三区组织；资料库两列布局 |
| 资料库打开方式 | 点击资料库外部失焦关闭；笔记单击以主界面 Lab 打开并关闭资料库，右侧支持 Lab / 便签模式打开 |
| 新建、重命名、删除、移动 | 拖拽移动；删除二次确认 |
| 颜色标签 | 重要 / 紧急 / 存档 / 待办 / 隐私等，按文件夹筛选 |
| 搜索 | 按标题搜索当前资料范围内的便签 |
| 打开所在文件夹 | 在资源管理器中定位当前便签 |

### 胶囊与提醒

| 功能 | 说明 |
|------|------|
| 胶囊模式 | 便签可缩成桌面胶囊，拖动、置顶、跨重启恢复 |
| Popout 小窗 | 便签可独立为小窗，继续编辑和同步标题 |
| 胶囊待办 | 一个胶囊可作为一个待办；点击完成后自动进入现有归档体系 |

### Quick Todo 与 Quick Pocket

| 功能 | 说明 |
|------|------|
| Quick Todo | 独立小窗待办：六类标签与筛选（含紧急、重要紧急）、父/子两层项目、拖拽排序、完成视图、定时提醒和关联 Markdown 便签；支持多个 Todo 独立存储、窗口状态与 S3 同步 |
| Quick 数据目录 | Todo / Pocket 分别选择目录，可共用；重启生效，统一读写与 S3 同步，不自动搬移文件 |
| Allnote Work | 可见窗口空闲时每 2 秒刷新共享文件；按项目折叠、多层父子任务、日期与来源入口。自动任务只读，手工任务继续正常编辑 |
| 提醒设置 | 在 Todo 窗口左侧优先弹出独立原生设置窗；一次性提醒到期后自动清除 |
| Quick Pocket | 独立快速收集窗：四类标签与筛选、标题/内文、失焦保存、隐私打码、内文复制、单层分组、组内新增和整组拖拽；支持多个 Pocket 通过 S3 云端权威自动同步；筛选时扁平显示条目 |

### 窗口与系统

| 功能 | 说明 |
|------|------|
| 无边框窗口 | 自定义顶栏与状态栏 |
| 托盘 | 关闭按钮隐藏到托盘，不结束进程 |
| 全局热键 | 默认 `Ctrl+Shift+Alt+N` 显示/隐藏 |
| 置顶 | 窗口始终在最前 |
| 明暗主题 | 浅色 / 深色 / 跟随系统；多套 accent 皮肤 |
| 顶栏 Logo | 点击将当前笔记转为胶囊模式 |
| 开机自启 | 可选 |
| 分离窗口 | 便签可拖到独立小窗 |

### 扩展能力

| 功能 | 说明 |
|------|------|
| 笔记上传 | 设置提供思源笔记 / Obsidian 两个 Tab，最多启用一个，也可全部关闭；主页面上传按钮跟随当前平台。思源保留单向上传至 `/MKnote/{标题}`；Obsidian 复制当前 `.md` 与本地附件，并调整附件链接，笔记支持重命名后复制或直接覆盖（待办和隐私笔记不上传） |
| Quick Capture | 快速捕获内容到 Inbox |
| 全文检索 | Omnibox 式搜索便签内容 |
| 最近访问 | 快速回到最近打开的便签 |
| 收藏 | 标记常用便签 |
| 双链 | 轻量 `[[链接]]` 与反向引用 |
| 图片 | 拖拽导入到 `File/assets/`；粘贴图片先保存本地副本，图床故障时仍可显示；图床设置提供兰空 / 云图选项卡和自动上传开关，关闭保留配置；云图使用访问密码并写入 `MDnote` 相册/目录；可手动扫描并将孤儿图片移入云图回收站 |
| Jev 自动归类 | 设置 → AI 配置选择官方或 Command Code、分别保存密钥与模型，并勾选已有候选文件夹及用途说明。状态栏可手动归类 Default 普通笔记；关闭 Tab 或关闭其他标签时，空白笔记移入回收站，非空 Default 普通笔记后台归类。已分类、隐私和专用默认笔记不参与；失败、无效候选或正文变化时不移动。本轮已通过用户验收 |
| AI 划词助手 | 配置 API 后对选中文本做辅助（可选） |
| 浏览器剪藏 | 本地 HTTP 服务接收剪藏内容 |
| Agent 索引 | 自动生成 `llms.txt`、`mknote-manifest.json` 供外部 AI 读取 |

### 分发方式

| 方式 | 说明 |
|------|------|
| 绿色便携版 | `npm run build:green` → exe + README，配置与便签与 exe 同目录 |
| 安装包 | NSIS / MSI（`npm run tauri build`） |
| 开发版 | `npm run tauri dev`，需 Node + Rust 环境 |

## 典型使用场景

1. **临时备忘**：热键弹出，记几句 Markdown，关窗隐藏。
2. **项目碎片**：按文件夹 + 颜色标签区分工作便签。
3. **桌面提醒**：把当前要做的事变成胶囊，完成后归档留痕。
4. **快速待办**：从 Quick Todo 记录项目、设置一次性提醒或关联已有 Markdown 便签。
5. **笔记归档**：本地 MKnote 起草，一键上传到思源，或复制到 Obsidian 的指定笔记与附件文件夹。
6. **与 AI 协作**：通过 `llms.txt` 让 Cursor 等工具读写本地便签（见 [AGENT-INTEGRATION.md](AGENT-INTEGRATION.md)）。
