## 功能一：脚本胶囊

### 背景

PaperTodo 的「脚本胶囊」允许笔记首行写 `!p` / `!power`，将整篇笔记内容作为 PowerShell 脚本运行。对技术用户而言，这让桌面便签变成了快捷命令面板，无需额外脚本管理工具。

MKnote 目前没有可执行笔记的概念。

### 目标

- 笔记内容首行为 `!p` 或 `!power` 时，编辑区工具栏显示「运行」按钮（⚡）
- 点击后将笔记正文（去除首行标记）作为 PowerShell 脚本执行
- 执行结果（stdout/stderr）以通知或内联提示呈现（本期简单弹 toast 即可）
- 不影响普通笔记的任何行为

### 方案设计

**触发识别（前端）**：

在 `CompactView.tsx` 中，监听 `content` 变化，检查首行：
```ts
const isScriptNote = content.trimStart().startsWith('!p\n')
  || content.trimStart().startsWith('!power\n');
```

若为脚本笔记，在工具栏追加一个 ⚡ 按钮，`onClick` 调用 `invoke('run_script', { content })`。

**Rust 侧执行（`src-tauri/src/` 新文件 `scripts.rs`）**：

```rust
#[tauri::command]
pub fn run_script(content: String) -> Result<String, String> {
    // 去除首行标记，取剩余内容作为脚本
    let script_body = content
        .lines()
        .skip(1)
        .collect::<Vec<_>>()
        .join("\n");

    let output = std::process::Command::new("powershell")
        .args(["-NoProfile", "-NonInteractive", "-Command", &script_body])
        .output()
        .map_err(|e| format!("启动 PowerShell 失败: {e}"))?;

    let stdout = String::from_utf8_lossy(&output.stdout).to_string();
    let stderr = String::from_utf8_lossy(&output.stderr).to_string();

    if !output.status.success() {
        return Err(if stderr.is_empty() { stdout } else { stderr });
    }
    Ok(stdout)
}
```

在 `lib.rs` 注册 `run_script` 命令。

**前端结果展示**：

调用成功显示绿色 toast（复用现有 `ErrorBanner` 的正向版，或直接 `alert` 先跑通），失败显示红色错误提示。

**安全说明**：
- 脚本以当前用户权限执行，和用户手动打开 PowerShell 执行等价
- 不做沙箱，这是用户显式写入 `!p` 触发的操作，属于用户自主行为
- 在 UI 上标注"将执行本机脚本"的确认提示（第一次运行弹确认框，记住选择）

### 涉及文件

| 文件 | 改动 |
|------|------|
| `src-tauri/src/scripts.rs` | **新文件**：`run_script` 命令 |
| `src-tauri/src/lib.rs` | `mod scripts`，注册命令 |
| `src/components/CompactView.tsx` | 检测脚本首行，显示 ⚡ 按钮 |
| `src/App.css` | ⚡ 按钮样式（复用工具栏按钮规范） |

### 验证方式
1. 新建笔记，首行写 `!p`，第二行写 `Write-Output "hello"`
2. 工具栏出现 ⚡ 按钮
3. 点击后显示 `hello`
4. 删除 `!p` 首行，⚡ 按钮消失
5. 普通笔记无任何变化

## 功能二：全屏避让

### 背景

MKnote 的便签默认置顶（`always_on_top: true`）。用户玩全屏游戏或做全屏演示时，便签会盖在全屏画面上，影响体验。

PaperTodo 提供了「全屏避让」选项：检测到外部全屏窗口时，可选择便签临时隐藏，或保持在全屏之上。

### 目标

- 新增设置项「全屏时自动隐藏」（默认关闭，不影响现有行为）
- 开启后：检测到其他程序进入全屏时，自动隐藏 MKnote 窗口到托盘
- 全屏结束后，自动恢复显示

### 方案设计

**全屏检测（Rust + Win32）**：

在 `win_present.rs` 或新文件 `fullscreen_watcher.rs` 中，用 Win32 API 轮询或事件驱动检测：

```rust
use windows::Win32::UI::WindowsAndMessaging::{
    GetForegroundWindow, GetWindowRect
};
use windows::Win32::Graphics::Gdi::{
    MonitorFromWindow, GetMonitorInfoW, MONITORINFO, MONITOR_DEFAULTTONEAREST
};

pub fn is_any_window_fullscreen() -> bool {
    unsafe {
        let hwnd = GetForegroundWindow();
        if hwnd.0 == 0 { return false; }

        let mut rect = Default::default();
        let _ = GetWindowRect(hwnd, &mut rect);

        let monitor = MonitorFromWindow(hwnd, MONITOR_DEFAULTTONEAREST);
        let mut info = MONITORINFO {
            cbSize: std::mem::size_of::<MONITORINFO>() as u32,
            ..Default::default()
        };
        let _ = GetMonitorInfoW(monitor, &mut info);

        rect.left <= info.rcMonitor.left
            && rect.top <= info.rcMonitor.top
            && rect.right >= info.rcMonitor.right
            && rect.bottom >= info.rcMonitor.bottom
    }
}
```

**轮询策略**：在 `setup` 中启动后台线程，每 2 秒检测一次（低频，CPU 开销可忽略）：

```rust
// 在 setup() 中，仅当配置开启时启动
if config.fullscreen_dodge {
    spawn_fullscreen_watcher(app.clone());
}
```

状态机：`was_fullscreen: bool`，检测到状态变化时才触发 hide/show，避免频繁操作。

**注意**：MKnote 自身窗口不算全屏（需排除自身 HWND）。

**配置**：

`AppConfig` 新增：
```rust
#[serde(default)]
pub fullscreen_dodge: bool,
```

前端设置页增加开关（在外观或系统集成区域）。新增 `set_fullscreen_dodge` Tauri 命令。

**边界情况**：
- 用户手动隐藏时不应在全屏结束后自动恢复（需区分"因全屏避让而隐藏"和"用户主动隐藏"两种状态）
- 后台线程生命周期绑定 `AppHandle`，应用退出时随之销毁

### 涉及文件

| 文件 | 改动 |
|------|------|
| `src-tauri/src/win_present.rs` 或新 `fullscreen_watcher.rs` | 全屏检测逻辑 + 后台轮询线程 |
| `src-tauri/src/system.rs` | `setup` 中条件启动 watcher |
| `src-tauri/src/lib.rs` | `AppConfig` 新增字段，注册 `set_fullscreen_dodge` |
| `src/App.tsx` 或设置组件 | 新增开关 UI |
| `src/App.css` | 开关样式（复用现有 toggle 规范） |

### 验证方式
1. 设置页开启「全屏时自动隐藏」
2. 打开一个全屏游戏或 `Win+向上箭头` 最大化（注：最大化 ≠ 全屏，需用真正全屏程序验证）
3. MKnote 窗口消失到托盘
4. 退出全屏，MKnote 自动恢复
5. 关闭设置，重复以上操作，便签保持正常置顶行为

## 两个功能的独立性

脚本胶囊和全屏避让**互相独立**，可分开实现，不共享代码。建议先做脚本胶囊（纯逻辑，无 Win32 依赖），再做全屏避让。

---

## 风险与注意事项

- **脚本胶囊**：PowerShell 执行是同步阻塞调用，长时间运行的脚本会卡住 Rust 命令线程。需用 `async` + `spawn_blocking` 包装，或给 `Command` 设置超时（30s）
- **全屏避让**：部分游戏（如抗拒置顶的 DirectX exclusive 全屏）行为与普通全屏不同，检测逻辑需实机验证；`GetForegroundWindow` 方案对某些游戏可能漏检
- `windows` crate 需确认已在 `Cargo.toml` 中启用相关 feature（`Win32_UI_WindowsAndMessaging`、`Win32_Graphics_Gdi`）；项目已有 `win_present.rs` 使用 Win32，需核查 feature 覆盖
