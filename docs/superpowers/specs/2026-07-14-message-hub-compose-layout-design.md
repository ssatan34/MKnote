# 短消息输入区布局调整设计

## 目标

将短消息输入区从“云端保险库按钮位于输入框上方、发送按钮位于输入框内部”调整为参考图 2 的布局：输入框位于左侧主体区域，云端保险库按钮位于右侧上方，发送按钮位于右侧下方。

## 范围与约束

- 只改变组件布局，不改变组件设计。
- 保留当前主题自适应，不引入参考图中的深色背景或金色边框。
- 保留云端保险库按钮现有图标、状态切换、交互与动画。
- 保留发送按钮现有图标、禁用态、hover/点击动画、快捷键和发送逻辑。
- 不调整消息列表、底部操作栏、云端保险库业务逻辑或消息服务。

## 实现方案

使用 CSS Grid 重排现有输入区：

- 左侧网格区域由消息输入框占据，并纵向撑满输入区。
- 右侧网格区域分为上下两行。
- 上方保留 `VaultCurtainButton`，仅移动其布局位置。
- 下方保留现有发送按钮，移出输入框并改为网格内的正常定位。
- 发送按钮的交互样式继续复用现有 `.message-hub-send-btn`，只覆盖布局定位相关属性。

## 变更文件

- `src/components/MessageHubView.tsx`：调整输入区 JSX 嵌套关系，不改状态或事件处理。
- `src/App.css`：调整 `.message-hub-compose`、输入框容器和发送按钮的布局规则。

## 验证

- `npm.cmd run build`
- `git diff --check`
- 检查工作区 diff，确认没有修改发送、保险库及消息列表业务逻辑。
- 运行界面后确认窗口尺寸变化时三者布局稳定，现有 hover、focus、发送禁用态仍生效。
