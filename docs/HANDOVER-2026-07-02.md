## 一、本轮新增功能

### 1. 隐私笔记（Private Notes）

**入口**：`Ctrl + 左键` 点击左上角 Logo

**数据目录**：`File/.private/`（以 `.` 开头，应用启动时自动设置 Windows 隐藏属性）

**行为**：
- 进入后**仅替换编辑区内容**为最近隐私笔记（无则自动创建）
- Tab 栏、标题栏、状态栏**完全不变**，视觉上看不出已切换
- 退出方式：点击任意 Tab（自动先保存隐私笔记内容）
- 隐私笔记不出现在资料库、最近打开、Agent 索引中
- 不参与撤销/重做历史（使用独立内存状态）

**实现**：
- `NoteZone::Private` 新增 zone 变体（`paths.rs`）
- `ensure_private_dir` 创建 `.private/` 并 `attrib +H`
- `App.tsx` 新增 `privateModeActive`、`handleEnterPrivateMode`、`exitPrivateMode`、`handleSelectTab`（包装 switchToTab）
- `CompactView.tsx` Logo 的 `onClick` 处理 `e.ctrlKey`，编辑区 content/onChange 根据 `privateModeActive` 切换

---

### 2. 云端保险库（Cloud Vault）

**入口**：短消息（Chat）界面，发送框上方左侧锁形图标按钮

**密码机制**：
- 密码 SHA-256 哈希后存在 S3：`{prefix}/vault-config.json`
- 首次使用弹出「设置密码」对话框（两次确认）
- 后续弹出「输入密码」验证
- 所有写操作（添加/删除/更新）在 Rust 侧重新校验密码
- 关闭 Chat 面板时自动清空内存中的解锁状态

**内容存储**：S3 `{prefix}/vault-notes.json`（prefix 从现有 `s3_object_key` 派生）

**界面**：
- 通过验证后在消息列表上方显示 Vault 面板
- 支持添加、双击编辑、删除、复制条目
- 右上角「锁定」按钮立即清空解锁状态
- 未配置 S3 时点击锁形按钮显示提示，不弹密码框

## 三、已知限制

| 项 | 说明 |
|----|------|
| 隐私笔记 undo/redo | 私密模式下不支持撤销重做（使用独立状态，未接入 useEditorHistory） |
| 隐私笔记多条切换 | 当前进入私密模式只加载最新一条，暂无私密空间内的 Tab 切换 UI |
| Vault 密码重置 | 不支持修改/重置密码（需手动删除 S3 的 vault-config.json） |
