# 发光条

## 用途

GBF 主题使用的无边框蓝色发光条资源。适合放在标题输入栏、Tab 激活态、主题示意卡片或其他 HUD 分隔位置。

## 视觉组成

- 中心：冰蓝色高亮核心；
- 两侧：蓝色渐隐延伸；
- 外层：蓝色柔和光晕；
- 不使用 `border`，避免出现矩形边框感。

## 可复用 CSS

```css
.mk-glow-bar {
  position: relative;
  height: 3px;
  border: 0;
  background: linear-gradient(
    90deg,
    transparent 0%,
    rgba(42, 133, 255, 0.32) 8%,
    rgba(57, 154, 255, 0.92) 24%,
    #dcf6ff 50%,
    rgba(57, 154, 255, 0.92) 76%,
    rgba(42, 133, 255, 0.32) 92%,
    transparent 100%
  );
  box-shadow:
    0 0 10px rgba(77, 167, 255, 0.98),
    0 0 24px rgba(40, 140, 255, 0.72);
  filter: blur(0.5px);
}
```

## 当前接入位置

- 顶部标题输入栏：`src/App.css` → `.compact-title-input-wrap::after`
- GBF 激活 Tab：`src/App.css` → `.note-tab.active::after`

## 使用约束

- 仅在 GBF 主题启用；
- 不要给发光条增加 `border` 或 `outline`；
- 如果需要更自然的过渡，优先扩大两侧透明渐变范围，不要降低中心亮度；
- 如果需要更强蓝色，优先提高 `rgba(57, 154, 255, 0.92)` 和光晕阴影，不要增加边框。
