## 功能与实现

- 文本与可视化编辑均支持选中多行后逐行生成待办；保留空行、已有任务及完成状态，自动折行不拆分，无选区保留原单行操作。顶层纯任务列表取消额外缩进，并保留与后续段落的间距。
- 文本模式复用行范围与格式撤销逻辑；普通列表转任务时移除已有列表标记，避免重复项目符号。
- 可视化模式按实际软换行与硬换行拆分，保留文字格式、已有任务状态及子列表，以一个事务完成转换。
- 任务样式修正仅作用于顶层纯任务列表，普通、混合及嵌套列表布局保持原规则。
